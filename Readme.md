# Fedora Tweaks & Optimization Scripts

A collection of simple shell scripts to improve **download speed**, **repository access**, and **battery life** on **Fedora Linux**.

These scripts are designed to be easy to use and work well on fresh or existing Fedora installations.

---

## 🚀 Fedora Tweaks: Faster Downloads & Extended Repositories

This script optimizes Fedora’s package manager (DNF) for faster downloads and enables commonly used repositories.

### What this script does
- Enables fastest mirror selection
- Improves DNF parallel downloads
- Adds useful Fedora repositories
- Updates system configuration for better package performance

### Run the script
```bash
curl -fsSL https://raw.githubusercontent.com/khan-debug/linuxessential/main/fedoraIS.sh | sh


## 🔋 Fedora Tweaks: Battery Optimization with TLP

This script installs and configures **TLP** to optimize power consumption and extend battery life on Fedora laptops.

### What this script does
- Installs TLP and required dependencies
- Enables TLP service at startup
- Applies recommended power-saving defaults
- Optimizes CPU, disk, and power usage
- Improves overall battery efficiency

### Run the script
```bash
curl -fsSL https://raw.githubusercontent.com/khan-debug/linuxessential/main/tlp.sh | sh
